## How to run it
File type: JavaScript (`.js`) 
File name: `server.js`

1. Install Node.js.
2. Open the terminal in VS Code and run:
npm init -y
npm install express body-parser

3. Run the program:
node server.js

4. Open Thunder Client and test these endpoints:

| Method | URL                             | Purpose       |
| ------ | ------------------------------- | ------------- |
| GET    | `http://localhost:3000/users`   | View users    |
| POST   | `http://localhost:3000/users`   | Add a user    |
| PUT    | `http://localhost:3000/users/1` | Update a user |
| DELETE | `http://localhost:3000/users/1` | Delete a user |

For POST and PUT, select Body → JSON in Thunderclient. Example:
{
  "name": "Amit"
}

This code stores data in memory, so the users reset when you restart the server.

##How to Run it
Step 1:
cd FSD-Codes/Exp9

Step 2: Install Dependencies
npm init -y
npm install dotenv express jsonwebtoken

Step 3: Create the Required Files
Create these three files inside your project folder:
jwt-project/
├── index.js
├── .env
└── package.json

Step 6: Start the Server
In the VS Code terminal, run:
node index.js

Expected output:
Server is up and running on 5000 ...

Keep the terminal open.

Step 7: Test Using Thunder Client
Open Thunder Client in VS Code and click New Request.
Request 1: Generate JWT Token
POST: Generate a token
URL: http://localhost:5000/user/generateToken
Configuration
- Select method POST.
- No request body or headers are required.
- Click Send.
Expected response: A long JWT string containing three parts separated by dots (.).

Request 2: Validate JWT Token
GET: Validate the token
URL: http://localhost:5000/user/validateToken
Configuration
1. Copy the JWT returned by Request 1.
2. Open the Headers tab in Thunder Client.
3. Add the following header:
Header name		| Value
gfg_token_header_key	| Paste your generated JWT here
4. Click Send.

Expected response
Successfully Verified
